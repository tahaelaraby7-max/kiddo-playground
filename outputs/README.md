# Kiddo Playground

A free, original kids' games website — memory match, tic-tac-toe, whack-a-mole, math quiz, and a maze game. Every game is code you wrote from scratch (via me), so it's fully yours to keep free, sell access to, or monetize later — no licensing issues.

## Files

```
index.html          homepage
css/style.css        shared styles
games/memory.html    memory match
games/tictactoe.html tic-tac-toe
games/whackamole.html whack-a-mole
games/mathquiz.html   math quiz
games/maze.html       maze runner
```

## Try it locally

Double-click `index.html` to open it in a browser — everything runs client-side, no install needed.

## Deploy for free — GitHub Pages

1. Create a free account at github.com if you don't have one.
2. Create a new repository (e.g. `kiddo-playground`), public.
3. Upload all these files/folders to it (drag-and-drop works on github.com, or use `git push`).
4. Go to repo Settings → Pages → set source to the `main` branch, root folder → Save.
5. GitHub gives you a live URL like `https://yourusername.github.io/kiddo-playground/` within a minute or two.
6. Optional: buy a custom domain later (e.g. from Namecheap, ~$10/year) and point it at the Pages site — the hosting itself stays free forever.

## Monetizing later (no cost to set up)

- **Ads**: Add Google AdSense once you have some traffic — free to join, pays you per impression/click.
- **Premium content**: Keep these games free, add new "premium" games behind a simple password or paywall page later (e.g. using Stripe Checkout, also free to integrate).
- **Sell as a template**: Since you own all the code, you could also sell the whole site as a template/package to other parents or small sites.

Start free, see if it gets traffic, then layer on monetization — no need to decide now.
